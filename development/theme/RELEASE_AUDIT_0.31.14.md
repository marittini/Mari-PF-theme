# 0.31.14 · 다섯 제보의 변경 및 검증

## 기준

ME 공식 main `c56501495a8baf76c258e76534c8728a9b7859bb`를 다시 조회했고 이전 조사와 동일함을 확인했습니다. 테마는 전달한 0.31.13 ZIP을 기준으로 하며, 수정 전 실행 JS/CSS/manifest가 그 ZIP과 일치함을 확인했습니다. 0.31.13 ZIP이 복구점입니다. 실제 사용자 서버의 설치 버전·확장 조합은 접근하지 못했습니다.

## 정확한 응답과 조회 범위

공식 `listMessagesPaginated`는 배열을 반환합니다. 이번 작업 중 배열이 아닌 응답을 원인으로 언급한 것은 잘못된 초기 판단이었고, 공식 저장소 구현을 읽은 후 정정했습니다. 그 추측을 근거로 API 형식을 바꾸지 않았습니다. 비정상 응답은 오류로 취급하며 빈 방으로 판정하지 않습니다.

미리보기는 기존 메시지 API를 이용해 최근 12개에서 보이는 텍스트를 찾습니다. 이는 순정 home-feed의 미리보기 조회 범위와 같습니다. 메시지는 있지만 최근 범위에 텍스트가 없으면 ‘텍스트 미리보기가 없는 메시지예요.’로 표시하여 방 자체가 비었다고 하지 않습니다. 전체 대화의 모든 메시지를 다운로드하지 않습니다.

속도 수치는 제어된 요청 횟수 검사입니다. 실서버 전체 로딩 시간·발열·배터리 향상을 실측한 결과가 아닙니다. 전역 요청/캐시 정책을 다시 최적화하거나 게임 방 생성/삭제 방식을 변경하지 않았습니다.

## 검사와 근거

- `v03114-regressions.cjs`: 위 알림·빈 판정·덮어쓰기·중복 조회·같은 timestamp 편집·지연 설정창/과거 트리 검사. `*-before.log`는 0.31.13 실패 재현 로그입니다.
- `v03114-browser.cjs`: 실제 빌드된 extension.js/CSS를 Chromium PC/터치에서 실행. 모의 HTTP와 native 저장소를 사용해 전체 목록·텍스트 변화·요청 횟수·토스트와 배지를 검사했습니다.
- `v031.cjs`: 기존 전체 기능 모의 회귀. `v0317-compat.cjs`: 선톡/미읽음·번역 DOM 원문/번역/편집 호환.
- `start-flow.cjs`, `setup-handoff.cjs`, `lazy-launch.cjs`: 각 모드 반복 생성·기존 방 진입·native/theme 순서별 게임 Back·지연 모드 선택창.
- `home-session.cjs`, `action-coherence.cjs`, `native-back-state.cjs`, `resume-races.cjs`: 홈 뒤 활성 방·다른 방 보존·취소/늦은 액션·복귀 경합.
- `message-state-regressions.cjs`: 이전 수정인 사용자 메시지 분할 유지와 명시적으로 확인된 빈 미리보기. lastMessageAt:null만으로 빈 방을 추정하던 과거 검사 전제는 제거했습니다.
- `game-delete-settlement.cjs`: 순정 삭제 hook 본문을 사용한 게임 취소 후 활성 ID 복구 유지.
- `panel-environments.cjs`, `game-setup-environments.cjs`: 위 환경 조건.
- `module-contracts.cjs`, `list-updates.cjs`, `build.py --check`: 상태/초기화/정리 계약, 목록·캐시 기존 동작, 생성 파일 일치.
- ZIP 필수 구성·소스 일치·추출 후 재빌드 결과는 `PACKAGE_VERIFICATION.json`에 기록합니다.

## 변경 통제

변경 실행 소스는 6개입니다: `engine/adapter.js`, `engine/mounts.js`, `engine/query-updates.js`, `features/chats.js`, `features/notifications.js`, `features/previews.js`.

그 외 실행 소스와 모든 스타일은 0.31.13 그대로입니다. 특히 launch/history/convo/data, 게임 생성/삭제 콜백, TTS/번역 DOM 처리, 설정 저장·테마 색상은 변경하지 않았습니다. 추가된 알림 객체 참조는 최근 500개로 제한하고 종료 시 해제합니다. 설정창 상태 정리에만 현재 Fiber 조회 옵션을 사용하며, 기존 API 탐색의 기본 동작은 바꾸지 않았습니다.

## 미검증

실제 React 엔진 전체·사용자 서버·물리 Android/iPhone·Safari/WebKit·Firefox·외부 확장 전체 조합은 미검증입니다. 모의 검사 통과를 이 환경들의 정상 작동으로 간주하지 않습니다. 5번 제보와 같은 모든 비동기 순서가 실환경에서 제거되었다고 단정하지 않습니다.
