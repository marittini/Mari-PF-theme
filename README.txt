마리나라 플랫폼화 0.22.0

설치
기존 Four Tabs를 이 ZIP으로 교체합니다. 별도 모바일 UI/뒤로가기 확장은 끕니다.
설치용 파일은 manifest.json, extension.js, extension.css입니다.

이번 변경
0.22 추가 변경
- 마이페이지 → 홈 보기 / 페르소나 라이브러리 보기에서 각각 갤러리뷰·스크롤뷰를 선택합니다.
  스크롤뷰는 프사와 이름·메모·태그를 가로로 배치한 세로 목록입니다. 폴더 구분과 원래 상세 열기를 유지합니다.
  선택은 브라우저에 저장되어 다시 실행해도 유지됩니다. 오늘의 캐릭터는 전용 추천 카드를 유지합니다.
- 로어북 항목의 ⋯ 설정은 해당 항목 내부에 펼쳐집니다. 화면 바깥으로 잘리지 않고 완료로 닫습니다.
- 프리셋은 제목/펼침 줄과 이동·그룹·액션 도구 줄로 정돈합니다. 제목은 줄바꿈하고 입력칸은 화면 폭에 맞춥니다.
- 로어북 도움말은 항목이 나타나는 DOM 변경 직후 추가합니다. 수정된 영역만 검사하고 반복 조회·폴링은 쓰지 않습니다.

이전 변경
1. 태그 추천을 브라우저 datalist 대신 입력칸 아래에 뜨는 확장 자체 목록으로 바꿨습니다.
   기존 태그를 검색·터치·클릭으로 선택합니다. 키보드 방향키/Enter로 선택하고 Esc로 닫을 수도 있습니다.
   선택한 태그는 원래 입력칸에 들어가며, 순정 추가 버튼/Enter로 등록합니다.
   로딩·빈 목록·오류 안내를 표시하고 원래 입력/저장 기능을 유지합니다.
2. 페르소나 갤러리의 이름·title/comment·태그를 홈처럼 왼쪽 정렬합니다.
3. 로어북 초보 안내와 도움말을 작은 rem 글자 크기로 표시합니다. 사용자 폰트를 상속합니다.
4. 로어북 항목 제목을 넓은 첫 줄로 배치하고 아이콘을 그 아래에 표시합니다.
5. 프리셋 섹션은 이동/위치 조절을 위쪽 왼편에 배치합니다.
   다음 줄에 펼침/접음 버튼과 제목을 나란히 두고 복사 등 액션은 오른쪽에 배치합니다.
   그룹/마커 배지와 원래 조작 기능을 유지합니다.
6. 홈의 캐릭터/폴더 구분에도 얇은 구분선을 추가합니다.
7. 홈·페르소나 목록과 폴더 정보를 병렬로 불러오고 캐시를 12개 범위에서 재사용합니다.
   화면 전환 시 해당 조회를 모두 취소합니다. 태그는 기존 엔진 전체 목록 캐시가 있으면 재사용하며
   없을 때만 필요한 페이지를 조회합니다. 저장 문자열 데이터의 태그도 해석합니다.
8. 순정 FloatingWindow의 채팅 설정창을 모바일에서 하단 메뉴 위 사용 영역 안에 맞춥니다.
   내부 스크롤과 아래쪽 여백으로 마지막 설정까지 접근할 수 있게 합니다.
   PC는 기존 이동 가능한 창 배치를 유지하며 사용 높이에 맞춰 최대 높이를 제한합니다.
9. 주기적 폴링을 추가하지 않았습니다. 태그 목록의 자체 DOM 갱신을 관리 화면 관찰에서 제외하며
   선택/색상/메시지 액션/뒤로가기 등 기존 동작의 회귀 검사를 유지합니다.

기존 기능
모바일 하단/PC 왼쪽 세로 메뉴, 공식 로고, 캐릭터 설명 마크다운, 페르소나 갤러리,
최근/전체 대화 미리보기, 순정 제작·설정·편집 연결, 확장 상단 버튼 바로가기,
대화 모드별 ID 진입, 모바일 뒤로가기 안내와 기본 호스트 종료 동작 위임 등을 유지합니다.

검증 범위
Chromium에서 지연 렌더·API·React/Zustand 스냅샷·순정 액션·history sentinel을 모의한 회귀 검사.
실제 사용자의 서버, 실제 Android, 설치된 외부 앱 전체 조합에서의 검증은 수행하지 못했습니다.
full_page_access 공개 API에 내비게이션 기능이 없어 기존 React 액션 스냅샷/콜백을 읽습니다.
공개 연결 API가 아니므로 엔진 빌드 변경에 영향을 받을 수 있습니다.
