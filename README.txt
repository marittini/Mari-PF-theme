마리나라 플랫폼화 0.31.2

설치
기존 확장을 이 ZIP의 manifest.json, extension.js, extension.css로 교체합니다.
첨부해 주신 번역 프리셋·단어장 확장은 수정할 필요가 없습니다.

이번 변경 (0.31.2 긴급 수정)
- 홈 캐릭터 → 대화 시작에서 순정 앱이 숨겨져 옵션창과 생성된 방이 보이지 않던 문제를 수정했습니다.
- 대화/롤플레이/게임 모드 선택 후 순정 프리셋·시나리오 등 설정 과정을 유지합니다.
- 실제 새 방의 ID를 확인한 뒤 방 진입을 완료하며, 시작 옵션을 임의로 초기화하지 않습니다.
- 모드 선택 취소는 원래 카드로 돌아옵니다. 시작 흐름 관찰은 완료/취소/다른 화면 이동 때 해제합니다.

0.31 변경
1. 문단 번역 확장의 원문/번역 화면 인접 관계와 클릭 동작을 보존합니다.
   해당 확장이 표시 중인 메시지는 테마에서 복제·줄바꿈 재분리하지 않습니다.
   원문으로 돌아오면 기존 테마 분리를 다시 적용합니다.
2. 모바일 브라우저 복귀 시 서버의 미확인 선톡 정보를 보충 조회합니다.
   오래된 쿼리 캐시를 건너뛰며 복귀 이벤트는 합쳐 처리합니다. 주기적 폴링은 없습니다.
3. 홈/페르소나 카드의 상세 소개는 Creator Notes만 표시합니다.
   없으면 '등록된 소개가 없어요.'로 표시하며 Description은 대신 표시하지 않습니다.
4. 마이페이지 제목 오른쪽에 도움말을 추가했습니다. AI 연결을 처음부터 설명하는 초보자 안내를 제공합니다.
   도움말 내용은 development/theme/content/help.md에서 편집할 수 있습니다.

도움말 편집
1. development/theme/content/help.md를 일반 텍스트 편집기로 수정합니다.
2. development 폴더에서 python3 theme/build.py를 실행합니다.
3. 생성된 development/theme/manifest.json, extension.js, extension.css로 확장을 교체합니다.
제목, 목록, 강조, 링크, 코드 블록을 사용할 수 있습니다. 도움말 내용은 빌드 시 포함됩니다.

개발/유지보수
기능별 29개 모듈이며 설치 방식은 그대로입니다.
MAINTENANCE.md와 MODULES.md에 소스 위치·연결·검사 절차가 있습니다.
브라우저 회귀 검사는 모의 엔진과 첨부 확장에서 추출한 DOM 함수로 수행했습니다.
실기기·실제 번역 API·설치된 모든 확장 조합 또는 발열 수치를 직접 측정한 것은 아닙니다.

이전 업데이트 기록
이번 변경 (0.29)
- 디자인 → 채팅 글자·여백 → 별도 번역문 크기 줄이기(0~12px)를 추가합니다.
  0px은 원문과 같은 크기입니다. 별도 표시 번역에만 적용하며 번역만 표시한 본문은 유지합니다.
  실시간 미리보기와 저장·복원을 지원합니다.
- 디자인을 색상 / 홈·라이브러리 / 채팅 글자·여백의 세 섹션으로 정리했습니다.
  지향색·배너·보기 방식·자간/행간·롤플레이 여백은 같은 위치에서 계속 설정합니다.

0.28 기능 유지
- 번역문 폰트 크기를 해당 메시지 원문의 실제 표시 크기에 연결합니다.
- 폰트 크기 변경·새 번역·번역만 표시에서도 본문 크기를 따릅니다.
- 번역문 행간·자간도 디자인 설정을 적용합니다. 메시지 내용과 번역 저장값은 수정하지 않습니다.

0.27 변경
- 같은 페르소나·같은 사진이면 현재 저장된 크롭을 우선합니다.
- 예전 메시지 스냅샷의 비어 있거나 오래된 크롭이 현재 설정을 가리지 않도록 수정했습니다.
- 다른 페르소나/다른 사진은 해당 메시지 스냅샷을 사용하며 표정 이미지는 덮어씌우지 않습니다.
- 크롭된 이미지의 순정 페이드 마스크를 제거해 캐릭터·페르소나 패널 표시를 통일합니다.

0.26 기능 유지
- 롤플레이 사용자 프사에 페르소나 크롭을 캐릭터와 같은 방식으로 반영합니다.
  현재 personaInfo와 메시지의 personaSnapshot을 사진·페르소나 식별 기준으로 구분합니다.
  표정 이미지가 원본 프사와 다르면 원본 크롭을 덮어씌우지 않습니다. 추가 페르소나 조회는 없습니다.
- 마이페이지 → 디자인 → 롤플레이 말풍선 좌우 여백(0~40px)을 추가합니다.
  실시간 반영·저장을 지원합니다. 직접 조절하기 전에는 기존 형식별 여백을 유지합니다.

0.25 변경
- 콘보 사용자 말풍선의 파란색 고정 그라데이션을 제거하고 지향색으로 연결합니다.
- 라이트·다크 모두 적용하고 지향색이 바뀌면 즉시 반영합니다. linear 배경은 유지합니다.

0.24 변경
- 설정 탭/모양 분류를 오가거나 다시 열 때 기본 접힘 상태로 돌아갑니다.
- 트래커 패널의 fieldset도 접기/펼치기에 포함합니다. 아이콘은 작은 화살표로 표시합니다.
- 검색어 입력으로 모든 설정을 펼치지 않습니다. 검색 결과 선택 시 해당 항목만 펼칩니다.
- 캐릭터·페르소나 카드와 카드 사이 공간에서 좌우 스크롤할 때 탭을 전환하지 않습니다.

0.23 기능 유지
1. 선톡 개수와 읽음 기록을 브라우저에 보관합니다. 순정 임시 목록이 비어도 지우지 않습니다.
   앱 새로고침·다른 앱 복귀·알림 닫기는 읽음 처리가 아닙니다. 방 진입 완료 시 해당 방 표시를 비웁니다.
2. 채팅 설정창을 포함한 SettingsSwitch 토글 손잡이 크기·이동을 통일합니다.
3. 갤러리는 격자, 스크롤은 좌우 스와이프 카드입니다. 홈 기본은 스크롤, 페르소나 기본은 갤러리입니다.
   기존에 저장한 선택이 있으면 유지합니다. 홈·페르소나를 각각 선택할 수 있습니다.
4. 마이페이지 → 테마 설정 아래 디자인을 누르면 별도 화면으로 들어갑니다.
   지향색, 홈 배너 표시, 홈/페르소나 보기, 채팅 자간(-1~4px)·행간(1.2~2.8)을 조절하고 저장합니다.
   글자 간격은 메시지 본문 중심으로 적용하며 사용자 폰트는 유지합니다.
5. 순정 설정의 기존 분류와 검색을 유지하면서 섹션별 접기/펼치기·모두 접기/펼치기를 추가합니다.
   검색 결과를 선택할 때 해당 항목을 펼쳐 원래 검색·포커스 기능을 사용할 수 있게 합니다.
6. 바로가기는 원래 확장 버튼의 핸들러를 호출합니다. 버튼이 재생성되면 현재 버튼을 다시 찾습니다.
   메시지/프롬프트 주입 이벤트를 차단하거나 채팅 요청 내용·헤더를 수정하지 않습니다.
7. 새 폴링 없이 기존 관찰자를 재사용합니다. 선톡 저장은 값이 바뀔 때만 기록하며 보관량을 제한합니다.

이전 기능 유지
- 폴더별 홈/페르소나 분류와 title/comment/태그, 매일 바뀌는 오늘의 캐릭터
- 선톡 알림 스와이프 닫기, 대화/롤플레이/게임 표시, 최근/전체 정렬
- 콘보 처리본 보존·줄바꿈 분리, 편집 중복/재생성·삭제 시 화면 이탈 수정
- 롤플레이 입력 집중 공간, 순정 제작/설정/편집 및 PC/모바일 이동
- 태그 자체 추천, 컴팩트한 관리 목록, 프리셋 배치/로어북 내부 설정 및 안내
- 병렬 조회, 캐시 재사용, 요청 취소, 화면 밖 이미지 지연 로딩

검증
Chromium의 모의 순정 엔진 계약으로 PC/모바일 회귀 검사를 수행합니다.
실제 Android·서버·설치된 외부 확장 전체 조합, 발열·배터리 개선률은 직접 측정하지 않았습니다.
순정 공개 내비게이션 API가 없어 내부 액션 스냅샷을 연결하며 엔진 변경의 영향을 받을 수 있습니다.
