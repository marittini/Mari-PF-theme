마리나라 플랫폼화 0.24.0

설치
기존 Four Tabs를 이 ZIP으로 교체합니다. 별도 모바일 UI/뒤로가기 확장은 끕니다.
설치용 파일은 manifest.json, extension.js, extension.css입니다.

이번 변경 (0.24)
- 설정 탭/모양 분류를 오가거나 다시 열 때 기본 접힘 상태로 돌아갑니다.
- 트래커 패널의 fieldset도 접기/펼치기에 포함합니다. 아이콘은 작은 화살표로 표시합니다.
- 검색어 입력으로 모든 설정을 펼치지 않습니다. 검색 결과 선택 시 해당 항목만 펼칩니다.
- 캐릭터·페르소나 카드와 카드 사이 공간에서 좌우 스크롤할 때 탭을 전환하지 않습니다.

0.23 기능 유지
1. 선톡 개수와 읽음 기록을 브라우저에 보관합니다. 순정 임시 목록이 비어도 지우지 않습니다.
   앱 새로고침·다른 앱 복귀·알림 닫기는 읽음 처리가 아닙니다. 방 진입 완료 시 해당 방 표시를 비웁니다.
2. 채팅 설정창을 포함한 SettingsSwitch 토글 손잡이 크기·이동을 통일합니다.
3. 갤러리는 격자, 스크롤은 좌우 스와이프 카드입니다. 홈 기본은 스크롤, 페르소나 기본은 갤러리입니다.
   기존에 저장한 선택이 있으면 유지합니다. 홈·페르소나를 각각 선택할 수 있습니다.
4. 마이페이지 → 테마 설정 아래 디자인을 누르면 별도 화면으로 들어갑니다.
   지향색, 홈 배너 표시, 홈/페르소나 보기, 채팅 자간(-1~4px)·행간(1.2~2.8)을 조절하고 저장합니다.
   글자 간격은 메시지 본문 중심으로 적용하며 사용자 폰트는 유지합니다.
5. 순정 설정의 기존 분류와 검색을 유지하면서 섹션별 접기/펼치기·모두 접기/펼치기를 추가합니다.
   검색 결과를 선택할 때 해당 항목을 펼쳐 원래 검색·포커스 기능을 사용할 수 있게 합니다.
6. 바로가기는 원래 확장 버튼의 핸들러를 호출합니다. 버튼이 재생성되면 현재 버튼을 다시 찾습니다.
   메시지/프롬프트 주입 이벤트를 차단하거나 채팅 요청 내용·헤더를 수정하지 않습니다.
7. 새 폴링 없이 기존 관찰자를 재사용합니다. 선톡 저장은 값이 바뀔 때만 기록하며 보관량을 제한합니다.

이전 기능 유지
- 폴더별 홈/페르소나 분류와 title/comment/태그, 매일 바뀌는 오늘의 캐릭터
- 선톡 알림 스와이프 닫기, 대화/롤플레이/게임 표시, 최근/전체 정렬
- 콘보 처리본 보존·줄바꿈 분리, 편집 중복/재생성·삭제 시 화면 이탈 수정
- 롤플레이 입력 집중 공간, 순정 제작/설정/편집 및 PC/모바일 이동
- 태그 자체 추천, 컴팩트한 관리 목록, 프리셋 배치/로어북 내부 설정 및 안내
- 병렬 조회, 캐시 재사용, 요청 취소, 화면 밖 이미지 지연 로딩

검증
Chromium의 모의 순정 엔진 계약으로 PC/모바일 회귀 검사를 수행합니다.
실제 Android·서버·설치된 외부 확장 전체 조합, 발열·배터리 개선률은 직접 측정하지 않았습니다.
순정 공개 내비게이션 API가 없어 내부 액션 스냅샷을 연결하며 엔진 변경의 영향을 받을 수 있습니다.
