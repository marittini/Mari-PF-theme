마리나라 플랫폼화 0.12.0

설치
기존 Four Tabs를 이 ZIP으로 교체합니다. 별도 모바일 UI/뒤로가기 확장은 끕니다.
설치용 파일은 manifest.json, extension.js, extension.css입니다.

이번 변경
1. 확장 이름을 '마리나라 플랫폼화'로 변경합니다.
2. 콘보 linear/bubble 메시지마다 위아래 여백을 추가하고 bubble 프사를 본문 상단에 맞춥니다.
3. 발열에 영향을 주는 반복 작업을 줄입니다. 줄바꿈 분리는 변경된 메시지 주변만 검사하며 변경 없는 표시본을 재사용합니다.
   관계없는 DOM 변경에는 메시지 전체 검사나 새 타이머를 만들지 않습니다. 편집·삭제·외부 TTS 처리본 교체 기능은 유지합니다.
4. 겹치는 알림 관찰 콜백을 한 번의 갱신으로 병합하고 동일한 배지 문구를 다시 쓰지 않습니다.
   메시지 액션마다 발생하던 불필요한 화면 준비 타이머를 줄입니다.
5. 백그라운드에서는 메시지 검사·알림 표시 갱신을 중단하고 장식 애니메이션을 일시 정지합니다.
   화면 복귀 시 한 번 동기화해 새 메시지와 편집 내용을 반영합니다.
6. 알림 드래그는 시작 시 너비를 한 번 읽습니다. 움직일 때마다 레이아웃 크기를 다시 읽지 않습니다.
   줄바꿈 범위 계산에서 매 줄마다 텍스트 노드 목록을 역순 복제하던 처리를 제거합니다.

기존 기능
모바일 하단/PC 왼쪽 세로 메뉴, 공식 로고, 캐릭터 설명 마크다운, 페르소나 갤러리,
최근/전체 대화 미리보기, 순정 제작·설정·편집 연결, 확장 상단 버튼 바로가기,
대화 모드별 ID 진입, 모바일 뒤로가기 안내와 기본 호스트 종료 동작 위임 등을 유지합니다.

검증 범위
Chromium에서 지연 렌더·API·React/Zustand 스냅샷·순정 액션·history sentinel을 모의한 회귀 검사.
실제 사용자의 서버, 실제 Android, 설치된 외부 앱 전체 조합에서의 검증은 수행하지 못했습니다.
full_page_access 공개 API에 내비게이션 기능이 없어 기존 React 액션 스냅샷/콜백을 읽습니다.
공개 연결 API가 아니므로 엔진 빌드 변경에 영향을 받을 수 있습니다.
